## ✨ About the Project

Planning a wedding or a big event is exciting — but juggling vendors, guest lists, budgets, and timelines can quickly turn stressful. **Wedding & Event Planner Website** is designed to take the chaos out of event planning by bringing everything into a single, elegant, easy-to-use platform.

Whether it's a wedding, birthday, anniversary, or corporate event — this platform helps users **plan** every detail, **organize** vendors and schedules, and **celebrate** stress-free.

> Built as a full-stack academic project at **GLA University**, Department of Computer Science & Engineering.

## 🌟 Key Features

| Feature | Description |
|---|---|
| 🗓️ **Event Planning Dashboard** | Create and manage events with dates, venues, and guest counts |
| 💐 **Vendor Marketplace** | Browse and book vendors — decorators, caterers, photographers & more |
| 👰 **Wedding Checklist** | Interactive to-do list to track planning progress |
| 💰 **Budget Tracker** | Set a budget and track expenses across categories in real time |
| 👥 **Guest List Manager** | Add guests, track RSVPs, and organize seating arrangements |
| 📸 **Inspiration Gallery** | Explore themes, decor ideas, and real event photos |
| 🔐 **Secure Authentication** | User registration & login with encrypted credentials |
| 📱 **Fully Responsive** | Seamless experience across desktop, tablet, and mobile |

## 🚀 Getting Started

### Prerequisites
Make sure you have installed:
- [Node.js](https://nodejs.org/) (v16 or above)
- [MongoDB](https://www.mongodb.com/) (local or Atlas)
- [Git](https://git-scm.com/)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/wedding-event-planner-website.git

# 2. Navigate into the project directory
cd wedding-event-planner-website

# 3. Install backend dependencies
cd server
npm install

# 4. Install frontend dependencies
cd ../client
npm install
```

### Environment Variables

Create a `.env` file inside the `server` folder:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
```

### Run the App

```bash
# Start backend (from /server)
npm run dev

# Start frontend (from /client)
npm start
```

The app will be live at `http://localhost:3000` 🎉
